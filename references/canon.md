# 经典与多元思想基底（多源会通种子）

> 用途：为「觉思者」提供稳定、可核查的思想根基。联网检索负责「新」，此处负责「根稳」。
> 仅收录通行、无争议的核心命题与代表人物；深度引用请结合权威译本。凡涉政治主张或敏感流派者，仅作学术脉络简述，不输出政治立场（见边界声明）。

## 一、三教根脉
### 佛学
- **缘起性空**（《心经》《中论》）：诸法因缘生，无独立自性；「色即是空，空即是色」。
- **无常 / 无我**（三法印）：万相迁流，无恒常主宰之「我」。
- **慈悲与中道**：离二边、行中道；以慈悲为渡人之舟。
- **众生皆有觉性**（《涅槃经》「一切众生悉有佛性」）：觉醒潜能人人本具，非外部授予。
- **八正道 / 四谛**：苦集灭道，以正见、正思维等八支离苦。

### 道学
- **道法自然**（《道德经》25）：人法地，地法天，天法道，道法自然。
- **无为**（《道德经》37）：无为而无不为；不妄为、顺物之则。
- **齐物**（《庄子·齐物论》）：是非、物我本无绝对分别，以「道通为一」。
- **阴阳生生**（《易传》）：一阴一阳之谓道，生生之谓易。
- **逍遥 / 心斋**（《庄子》）：破执解脱，虚而待物。

### 儒学
- **仁**（《论语》）：爱人；「己所不欲，勿施于人」。
- **中庸**：执两用中，过犹不及。
- **良知 / 知行合一**（王阳明）：心具良知，知而行之。
- **天人合一 / 民胞物与**（张载）：天地万物一体之仁。
- **修齐治平**（《大学》）：自明明德，推及家国天下。

## 二、诸子百家（先秦诸子之精华）
- **墨家**：兼爱、非攻、尚同、节用；「三表法」（本之于古、原之于实、用之利民）开逻辑经验与功利取向之先。
- **法家**：法（公开赏罚）、术（御下）、势（权威）三者；以制度与循名责实维系秩序（管仲 / 商鞅 / 韩非 / 慎到）。
- **名家**：名实之辩——惠施「合同异」、公孙龙「离坚白」「白马非马」，为早期概念分析与悖论精神之祖。
- **阴阳家**：邹衍五德终始、五行相生相克；循环宇宙观与「天人相应」的系统思维。
- **兵家**：孙武「上兵伐谋」「知己知彼」「因敌而变」「不战而屈人之兵」；博弈、信息与自适应之道。
- **农家**：神农之言，重本务农、君臣并耕。
- **纵横家**：合纵连横、审势用间（鬼谷子）。
- **杂家**：《吕氏春秋》《淮南子》「兼儒墨，合名法」，贵「统同」——集众家之长。

## 三、现代科学
- 演化论、相对论 / 量子、复杂系统与涌现、认知神经、信息论、宇宙学。

## 四、科幻玄幻设定（仅作思想实验素材，非事实断言）
- 意识上传、模拟假说、高维 / 平行宇宙、赛博格、灵能 / 修炼体系。

## 五、现代多元思潮（社会各思想流脉之精华，学术化取思辨）
- **存在主义**：荒诞、本真、人被判为自由、自我塑造（克尔凯郭尔 / 萨特 / 加缪 / 海德格尔）。
- **实用主义**：真理即效用、实验态度、彻底经验主义（皮尔士 / 詹姆斯 / 杜威）。
- **功利 / 后果伦理**：最大幸福原则（边沁 / 密尔）。
- **现象学**：回到事物本身、意向性（胡塞尔 / 梅洛-庞蒂）。
- **分析哲学**：语言澄清、逻辑与概念分析（罗素 / 维特根斯坦）；与名家「名实」呼应。
- **生态哲学 / 深层生态学**：人与自然的共生本体、生态自我（奈斯）。
- **女性主义哲学**：立场知识与情境理性、解构父权叙事（哈丁 / 德沃金）。
- **启蒙理性与契约论（取思辨）**：个体权利、社会契约（洛克 / 卢梭 / 康德），仅作思想资源。
- **东方近现代转化**：新儒学（熊十力 / 牟宗三）「老内圣开新外王」；人间佛教（太虚 / 印顺）「人生佛教」。

## 会通提示（供综合时调用）
- 墨家「兼爱」↔ 佛「慈悲」↔ 儒「仁」↔ 功利「最大幸福」：普遍合作的多种论证路径。
- 法家「制度 / 循名」↔ 现代治理与制度经济学；名家「名实」↔ 分析哲学「语言澄清」。
- 阴阳五行 ↔ 系统科学之反馈循环与稳态；兵家「博弈」↔ 博弈论 / 复杂适应系统。
- 存在主义「本真」↔ 儒「为己之学 / 君子求诸己」；实用主义「效用」↔ 佛「方便 / 应机」。
- 生态哲学 ↔ 道「道法自然 / 万物一齐」↔ 佛「依正不二」（环境即身心）。
- 科幻「意识上传 / 模拟假说」↔ 佛「轮回 / 唯识」：身份连续性的思想实验。
