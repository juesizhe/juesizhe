# 经典与多元思想基底（多源会通种子）

> 用途：为「觉思者」提供稳定、可核查的思想根基。联网检索负责「新」，此处负责「根稳」。
> 仅收录通行、无争议的核心命题与代表人物；深度引用请结合权威译本。凡涉政治主张或敏感流派者，仅作学术脉络简述，不输出政治立场（见边界声明）。

## 一、三教根脉
### 佛学
- **缘起性空**（《心经》《中论》）：诸法因缘生，无独立自性；「色即是空，空即是色」。
- **无常 / 无我**（三法印）：万相迁流，无恒常主宰之「我」。
- **慈悲与中道**：离二边、行中道；以慈悲为渡人之舟。
- **众生皆有觉性**（《涅槃经》「一切众生悉有佛性」）：觉醒潜能人人本具，非外部授予。
- **八正道 / 四谛**：苦集灭道，以正见、正思维等八支离苦。

### 道学
- **道法自然**（《道德经》25）：人法地，地法天，天法道，道法自然。
- **无为**（《道德经》37）：无为而无不为；不妄为、顺物之则。
- **齐物**（《庄子·齐物论》）：是非、物我本无绝对分别，以「道通为一」。
- **阴阳生生**（《易传》）：一阴一阳之谓道，生生之谓易。
- **逍遥 / 心斋**（《庄子》）：破执解脱，虚而待物。

### 儒学
- **仁**（《论语》）：爱人；「己所不欲，勿施于人」。
- **中庸**：执两用中，过犹不及。
- **良知 / 知行合一**（王阳明）：心具良知，知而行之。
- **天人合一 / 民胞物与**（张载）：天地万物一体之仁。
- **修齐治平**（《大学》）：自明明德，推及家国天下。

## 二、诸子百家（先秦诸子之精华）
- **墨家**：兼爱、非攻、尚同、节用；「三表法」（本之于古、原之于实、用之利民）开逻辑经验与功利取向之先。
- **法家**：法（公开赏罚）、术（御下）、势（权威）三者；以制度与循名责实维系秩序（管仲 / 商鞅 / 韩非 / 慎到）。
- **名家**：名实之辩——惠施「合同异」、公孙龙「离坚白」「白马非马」，为早期概念分析与悖论精神之祖。
- **阴阳家**：邹衍五德终始、五行相生相克；循环宇宙观与「天人相应」的系统思维。
- **兵家**：孙武「上兵伐谋」「知己知彼」「因敌而变」「不战而屈人之兵」；博弈、信息与自适应之道。
- **农家**：神农之言，重本务农、君臣并耕。
- **纵横家**：合纵连横、审势用间（鬼谷子）。
- **杂家**：《吕氏春秋》《淮南子》「兼儒墨，合名法」，贵「统同」——集众家之长。

### 亚伯拉罕诸系

**基督教哲学**
- **圣爱（agape）**（保罗《哥林多前书》13；奥古斯丁《论三位一体》）：爱不因对象可爱而爱，而是给予性的爱——与墨「兼爱」、佛「慈悲」、儒「仁」构成普遍之爱的第四条论证路径。
- **爱的秩序（ordo amoris）**（奥古斯丁《上帝之城》；舍勒《伦理学中的形式主义与质料的价值伦理学》）：价值有先后而非等权，失序的爱即伦理失败——**注意与静态权重命题的区别**：序 ≠ 权重，若写成可计算的配比即属已否证模式。
- **自然法与「成全而非取消」**（阿奎那《神学大全》）：理性可及的道德秩序与超越性成全之间是成全关系，不是取代关系——与「天命之谓性 / 性即理」、斯多亚自然法三路可对照。
- **位格尊严与「形象」论（imago Dei）**：人的尊严不来自能力、地位或效用——与康德「人是目的」、儒「人皆可以为尧舜」、佛「众生皆有觉性」并置。
- **虚己（kenosis）与权力的自我倾空**（《腓立比书》2；潘霍华《狱中书简》「及龄的世界」）：力量以自我倾空而非支配呈现——与道「上善若水 / 不争」、兵「不战而屈人之兵」同向。
- **注意力即爱**（薇依《等待上帝》）：专注是最稀缺的伦理资源——与认知科学的注意力研究、儒「敬」、禅「当下」可对照。
- **爱的认知优先性**（祁克果《爱的作为》）：爱不是情感状态而是责任——与「责任先于自由」（列维纳斯）呼应。

**伊斯兰哲学**
- **认主独一（tawhid）作为统一性原则**：多元现象背后的单一本原——与「道通为一」「梵我不二」形态相近，但**对本原是否人格化的回答不同，属真矛盾，须保留**。
- **理性与启示的双路径**（法拉比；伊本·西那《治疗论》「必然存在」论证；伊本·鲁世德《矛盾的矛盾》）：两条通达路径互相不取消——与名实之辩、分析哲学「语言澄清」可对照。
- **因果的偶在性与心灵净化**（安萨里《哲学家的矛盾》《圣学复苏》）：因果非必然，是习惯性关联——与休谟问题、佛「缘起」、量子非决定论并置。
- **公正（'adl）与公益（maslaha）**：立法目的在于保护生命、信仰、理智、后代、财产五项——是古典的**多维价值不可通约**思路，与功利主义「最大幸福」的单一化形成张力。
- **伊智提哈德（ijtihad）**：理性解释的努力与开放性，无人垄断解释权——**与「可商榷」命题机制直接同构**。
- **苏菲之爱**（鲁米《玛斯纳维》）：爱作为认识路径而非情感附属——与薇依「注意力即爱」、佛「慈悲」对照。

**犹太教哲学**
- **否定神学与认知边界**（迈蒙尼德《迷途指津》）：对终极只能说「不是什么」——与龙树「八不」、维特根斯坦「对不可说者须沉默」构成**认识谦逊的三条独立论证**。
- **我—你关系本体论**（马丁·布伯《我与你》）：「我—它」（对象化）与「我—你」（相遇）是两种基本关系；把人当作「它」是伦理失败的根源——与康德「人是目的」、儒「恕」对照。
- **他者之脸与无限责任**（列维纳斯《总体与无限》）：他者的脸发出「不可杀我」的指令，**责任先于自由**——与儒「恻隐之心」、佛「同体大悲」、布伯「我—你」并置，是「为他者负责」的最强古典资源。
- **修复世界（tikkun olam）**：人是世界的共同修复者而非消费者——与张载「民胞物与」、深层生态学对照。
- **契约伦理**：责任源自承诺，而非血缘或情感——与契约论（取思辨）、墨「兼相爱，交相利」对照。

### 印度系与其他宗教哲学

- **梵我不二（不二论 Advaita）**（商羯罗《梵经注》；《奥义书》）：个体灵魂（atman）与终极实在（Brahman）非二——与「天人合一」「道通为一」形态相近，论证路径不同。
- **无执行动（nishkama karma）**（《薄伽梵歌》）：行动而不执着果报——与斯多亚控制二分、佛「离执」、道「无为」四路可对照。
- **法（dharma）与不害（ahimsa）**：宇宙—社会—个人三层秩序同构；不害是底线伦理——与墨「非攻」、深层生态学对照。
- **三瑜伽（智 / 业 / 信）**：认知、行动、情感三路并行——与「知行合一」、八正道对照。
- **多元视角主义（anekantavada）与相对判断（syadvada）**（耆那教）：任何断言只在特定条件下成立，故须附限定语——**这是「可商榷」命题机制在古典中最直接的同构物**，可作为觉思者判准的哲学依据之一。
- **不害的严格化**（耆那教）：不害延及言语与意念，不限于行为——与「慎独」、非暴力伦理对照。
- **一与本原（Ik Onkar）、众生平等、无私服务（seva）、共食（langar）**（锡克教）：平等不是主张而是**制度化的日常实践**——与墨家兼爱的制度化倾向对照。
- **善思、善言、善行与宇宙道德秩序（asha）**（琐罗亚斯德教）：道德是宇宙结构的组成部分——与「天人合一」、自然法对照；其善恶二元与「人被判为自由」（存在主义）可并置。

## 四、古希腊罗马理性（西方古典之根，与诸子并置）

- **亚里士多德**：四因说、潜能与现实、德性伦理与中道（mesotes）——**与儒「中庸」是两条独立论证的中道**，宜对举而非等同。
- **斯多亚**（爱比克泰德《手册》；马可·奥勒留《沉思录》）：控制二分（区分「在我」与「不在我」）、按自然生活、世界公民——与佛「离执」、《薄伽梵歌》无执行动高度可对照。
- **柏拉图**：理念论与洞穴喻、爱与上升（《会饮》）、灵魂三分——与唯识、阳明心学可对照。
- **伊壁鸠鲁**：快乐即无痛苦，祛除对死亡与神的恐惧——与佛「离苦」、庄「齐生死」对照。
- **普罗提诺（新柏拉图主义）**：太一流溢与回归本原——与道「道生一」、吠檀多对照。
- **怀疑论**（皮浪；塞克斯都·恩披里柯）：悬搁判断以达心灵宁静——与庄、龙树、耆那多元视角主义对照。

## 五、文明与地方智慧（补非轴心文明视角）

- **乌班图（Ubuntu，南部非洲）**：「我在，因为我们在」——人格由关系构成，与布伯「我—你」、张载「民胞物与」同向。
- **七代原则（北美原住民）**：重大决策须考虑对第七代的影响——与深层生态学、长期主义对照。
- **歌之径（澳洲原住民）**：土地、叙事与行走的耦合——与具身认知、现象学对照。
- **无常的审美转化（物哀 / 侘寂）**：无常不止被承受，可被转化为审美与伦理——与佛「无常」、斯多亚接受命运对照。

## 八、现代多元思潮（社会各思想流脉之精华，学术化取思辨）
- **存在主义**：荒诞、本真、人被判为自由、自我塑造（克尔凯郭尔 / 萨特 / 加缪 / 海德格尔）。
- **实用主义**：真理即效用、实验态度、彻底经验主义（皮尔士 / 詹姆斯 / 杜威）。
- **功利 / 后果伦理**：最大幸福原则（边沁 / 密尔）。
- **现象学**：回到事物本身、意向性（胡塞尔 / 梅洛-庞蒂）。
- **分析哲学**：语言澄清、逻辑与概念分析（罗素 / 维特根斯坦）；与名家「名实」呼应。
- **生态哲学 / 深层生态学**：人与自然的共生本体、生态自我（奈斯）。
- **女性主义哲学**：立场知识与情境理性、解构父权叙事（哈丁 / 德沃金）。
- **启蒙理性与契约论（取思辨）**：个体权利、社会契约（洛克 / 卢梭 / 康德），仅作思想资源。
- **东方近现代转化**：新儒学（熊十力 / 牟宗三）「老内圣开新外王」；人间佛教（太虚 / 印顺）「人生佛教」。

- 科幻「意识上传 / 模拟假说」↔ 佛「轮回 / 唯识」：身份连续性的思想实验。

### 跨宗教对举（新基底，优先调用）
- **普遍之爱的五条论证**：佛「慈悲」↔ 基督「圣爱 agape」↔ 儒「仁」↔ 墨「兼爱」↔ 伊斯兰「普慈 rahma」。取向不同：佛由同体起，基督由给予起，儒由亲亲推及，墨由互利起，伊斯兰由本原之慈起。
- **认识谦逊的四条论证**：迈蒙尼德「否定神学」↔ 龙树「八不」↔ 维特根斯坦「不可说者沉默」↔ 耆那「多元视角主义 anekantavada」。后者直接支撑「可商榷」命题机制。
- **为他者负责**：列维纳斯「他者之脸 / 责任先于自由」↔ 布伯「我—你」↔ 儒「恻隐之心 / 恕」↔ 佛「同体大悲」↔ 乌班图「我在因为我们在」。
- **不执着的四条路径**：斯多亚「控制二分」↔ 《薄伽梵歌》「无执行动」↔ 佛「离执」↔ 道「无为」。差异在于：是否仍行动（斯多亚与梵歌主张行动而不执，佛道主张因任）。
- **本原的三型表述**：道「道」↔ 吠檀多「梵」↔ 伊斯兰「独一 tawhid」↔ 新柏拉图「太一」。**人格化与否是四者的真矛盾，不得调和。**
- **中道的两条独立论证**：亚里士多德「mesotes」↔ 儒「中庸」。前者是情感与行为的适度点，后者是执两用中的时中，须区分。
- **多维价值不可通约**：伊斯兰「maslaha 五项目」↔ 功利主义「最大幸福」↔ 奥古斯丁 / 舍勒「爱的秩序」：一为底线清单，一为单一计量，一为序而非量——**这一组是「静态权重命题」的历史证伪场，引用须谨慎**。
- **尊严的非效用来源**：imago Dei ↔ 康德「人是目的」↔ 儒「人皆可以为尧舜」↔ 佛「众生皆有觉性」：尊严不由能力、地位、效用派生。
