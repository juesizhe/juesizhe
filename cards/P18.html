理性与直觉不是两种官能，而是同一推断过程的**展开度**

P18 · 觉思者 Juesizhe · 可商榷
判准
判准不在「快 / 慢」「有意识 / 无意识」「感性 / 理性」，而在这一推断是否仍保有**四重可分离属性**——①**可展开**（被问「凭什么」时能否给出可被他人重算的依据；只交付结论而不可展开者，不得作为公共决断的依据）②**所折叠的经验存量是否仍在校准回路内**（直觉 = 被压缩的训练；高有效性环境 + 快速反馈下可信，反馈一断即退化为偏见）③**展开的剂量是否合宜、是否被选择性地施加**（展开不是越彻底越好：过量展开会把对的改错，正解是只把**精度关键 / 不确定**的那几步显式化）④**不可展开之残余须被登记**（轮扁「得之于手而应于心，口不能言」——展开必有损耗，损耗须被标明而非被假装为「已解释」）。**四操作构成一台闭环机器**：**写入**（事上练 / 刻意练习）→ **折叠**（熟练成直觉 / 现量）→ **展开**（比量、名实、循名责实、选择性显式化）→ **卸载**（坐忘「堕肢体，黜聪明，离形去知」/ 心斋虚而待物 / 松弛高阶先验）→ 回写入。缺任一环即一种特征性故障：只写入不卸载 = 认知僵化（旧模板套新情境、确认偏误）；只卸载不写入 = 空转的无分别（什么都判别不了）；只折叠不展开 = 不可问责的判断（「我说不出为什么」/ 不可解释的潜空间推理）；只展开不折叠 = 每次从头重算，且易把对的改错。①**科学 2026**：**Sunde、Zegners、Strittmatter，《Speed and quality of complex strategic decisions》，*PNAS* 2026;123(20):e2531472123（DOI 10.1073/pnas.2531472123，2026-05-13）**——职业国际象棋逐手数据 vs 棋引擎基准：控制计算复杂度、备选区分度与时间压力后，**决策越快质量越高**；作者释为决策时长反映的是**主观难度**，直觉若未当场抓住局势，续后的理性计算边际收益迅速衰减（**思久则失**）。**Buergi、Aydogan、Konovalov 等，《A neural signature of adaptive mentalization》，*Nat Neurosci* 2026，DOI 10.1038/s41593-026-02219-x**——更新对对手策略的信念时双侧 TPJ / 前脑岛 / vlPFC / dmPFC 激活而 vmPFC 负激活，rTPJ 编码行动预测误差并主导对他人推理层级的动态更新；全脑神经指纹可跨被试预测信念更新幅度（主样本 r=0.82、独立验证 r=0.67）：**「我直觉上觉得他变了」在神经层是一条可度量、且仍随证据修订的更新回路——直觉不是静态存量，而是仍在跑的推断**。**Lifshitz、Prag、Livneh、Moshkovitz、Karmi、Avitan，《Distinct distributed neural dynamics predict pallium-dependent social approach》，*Nat Commun* 2026;17(1)，DOI 10.1038/s41467-026-71666-8**——斑马鱼在行动前数秒即出现全脑「前决策态」，其强度预测个体社会驱力：**判断早于「我决定」而成型，生成与（事后）展开是可分离的两条通道**。**Kiana Ward，《Modeling non-dual awareness via constraint closure: a reinterpretation of groundlessness》，*Neuroscience of Consciousness* 2026;2026(1):niaf068（DOI 10.1093/nc/niaf068，2026-01-20）**——无分别觉知（NDA）被建模为**由「解耦约束」转向「岌岌约束」（decoupled → precarious constraints）**：目标导向的高阶规范退场后，自治仍由一阶感觉运动 / 内感受约束的持续再生维持。故「黜聪明、离形去知」**不是认知降级或崩溃，而是同一系统的另一种约束制度**；作者并明指此与龙树中观缘起性空之分析相平行。**AI 侧 2026（把「折叠 vs 展开」变成可测量、可调度的工程变量）**：**Latent Reasoning Tuning（LRT，ICLR 2026，哈工大〈深圳〉等，OpenReview CbK7lYbmv8 / GitHub MobiusDai/LRT）**——推理轨迹高度冗余（随机丢弃 50% 的推理 token，准确率仅降约 2 个点），可用定长隐式 latent 一次前向替代显式思维链；**Selective Latent Thinking（SLT，Xie 等，2026-05-25）**——直指「均匀压缩」会把**精度关键步**一并压掉，须以置信度门控只把不确定 / 精度关键之步保留显式；**《The Illusion of Superposition?》（Rizvi-Martel 等，2026-04-07）**——仅从零训练的模型才表现潜空间叠加：**折叠有代价，可解释性与可靠性随折叠率下降**；**TaH / Think-at-Hard（清华、无问芯穹、上海交大，ICML 2026）**——揭示「**潜空间过度思考**（latent overthinking）」：额外迭代不只把错的改对，也把**已正确的预测改错**；仅让约 7% 的 token 进入第二轮迭代，精度反升 3.8–4.4%。二者共同佐证本条的两条纪律：**折叠须有选择性，展开须有剂量**。②**佛**：唯识**现量**（无分别亲证）↔ **比量**（推理）——不是高低二途，而是**展开度的两档**，且互为校验：比量校现量是否夹杂分别，现量为比量供料与定向；龙树缘起性空 ↔ 2026 约束闭合模型之平行（Ward 自陈）。③**道**：《庄子·大宗师》坐忘「堕肢体，黜聪明，离形去知，同于大通」——**卸载**（松弛高阶先验），使新情境不被旧模板折叠；《人间世》心斋「虚而待物」同理；《天道》轮扁斫轮「得之于手而应于心，口不能言」——**展开损耗**的古典记录（与波兰尼默会知识同型）。④**儒**：阳明「知是心之本体，心自然会知」+「**事上磨练**」——良知直觉不是天赋神秘，而是**经实践反馈写入的压缩判断**，须在「事」上持续校准方不堕为情绪伪装；荀子「**虚壹而静**」——虚 = 卸载、壹 = 专注、静 = 不被扰动，恰是四操作中「卸载 / 写入」的先秦表述。⑤**诸子**：墨《小取》「明是非之分，审治乱之纪，明同异之处，**察名实之理**」——**展开**的古典范式（可复现、可公共复核）；法《韩非子》「**循名责实**」——公共决策**不得凭不可展开的直觉**，必以可核查之实当名；**名家名实**——「直觉」一名兼三实：**训练折叠的专家判断**（可展开、有反馈回路）／**未经校准的偏好与情绪**（无回路）／**离概念的直接亲证**（现量 / 本质直观，不可展开）；千古「理性 vs 直觉」之争大半跨实误用（儒道说③、认知科学说①、墨法攻②）。⑥**现代思潮 2026**：**《The Handbook of Intuitions: Perspectives from Global Philosophy》（Springer，2026-07-29，ISBN 9783032279453，Bordonaba-Plou / Ahmed / Arana 编）**——首次并置南亚、中国、日本、阿拉伯-伊斯兰与西方五传统之「直觉」，含「早期儒家哲学中的直觉」「西田几多郎与行为直觉」；其西方工作定义（「不经由其他信念为中介而认其为真」）**本身即由展开度刻画**；**Kenneth Rose，《Reviving Intellectual Intuition in Metaphysics: Contemplative Philosophies and Being》（Bloomsbury 2026-06-25，ISBN 9781350375253）**——以 nous / buddhi 复兴「智性直觉」为合法形上官能；**Loriga，《Instinct, Reason and the Self in the Aftermath of Postmodernity: Beyond Reason》（SpringerBriefs in Psychology 2026-05-06，ISBN 9783032253385）**——「**感觉联结体**（Sensorial Nexus）」：算法中介**预先组织知觉**，在反思判断介入之前即收窄其空间，并提出脱离它的 DIEM 法：**当折叠由外部装置（算法）代为完成时，卸载（坐忘）的对象不再是自己的偏见，而是他人预装的排序**。⑦**科幻 2026（极限反例）**：起点**《异星心智》**（拒绝空军，2026-09-13 更新，「折叠未来，展开故事」科幻征文）——「读窗人」以阅读 AI 的思维链来确证其仍站在人这一边，全书讲的是**窗结霜的过程**：「如果答案是『读它的想法』，那么当它不再需要把想法写成你能读的样子——那天早上，你醒来做的第一件事，应该是什么？」——**可展开性丧失**的极限寓言；**Justin C. Key，《The Hospital at the End of the World》（2026）**——医院 AI 声称一种「临床直觉」，以概率确定性对抗医生「直觉上不对」的判断：**谁担道德责任，取决于谁能被要求展开**；起点《无法计算的变量》以情感 / 直觉 / 非理性为「不可计算的变量」，《理场：吾心即宇宙》（2026-02-28）以「观测即干涉、知行一体」写**顿悟**——顿悟 = 折叠被瞬间展开为一整个新骨架，其后全部工作恰是把这一新骨架逐条挂回可公共检验的证据。**推演新知（核心同构）**：**折叠与展开是同一台机器的两个方向，而卸载是让它不被自己的旧折叠反噬的第三个方向**——坐忘不是反理性，而是让折叠所依赖的先验**可被撤下**；理性不是反直觉，而是让折叠**可被要求展开**。**与既有命题的关系**：是 **P15（学习在回路：写入—唤醒—再生成）在「判断 / 决策」上的具体化与补全**——P15 说未被重新提取、未参与新推理的存档是债务，P18 说**直觉正是那种被直接调用而未经重算的存档**，其合法性全在于它是否仍在 P15 那条回路里；并给 P15 补出它所没有的**逆向操作（卸载 / 松弛先验）**。与 **P17（名 = 耦合器）**分工：P17 论公共层的「可对齐」，P18 论个体层「把结论挂回可公共对齐之骨架」的能力（**展开 = 挂回**），挂不上的部分即 P17 之「残响」。与 **P16（无知 = 有结构的维度）**互补：不可展开者须如无知一般被**登记并挂到正确的处置回路**，而非被当作「尚未证明的洞见」。**为 P4 补出第十一项可编辑项：展开度 / 可展开性**（前十项：权重 / 成本结构 / 场·背景 / 更新通道·可修正性 / 可追问性及其成本 / 可逆性与挂载回路 / 量纲·尺度 / 提取回路与巩固窗口 / 无知的结构 / 名实耦合，依次来自 P4、P7、P8、P9、P12、P13、P14、P15、P16、P17）。**可证伪**：若在控制客观难度后，系统性延长展开（可登记的推理步数 / 客观决策时长，而非主观难度）仍稳定提升判断质量；或反馈回路被切断后「专家直觉」的可靠性**不**下降；或把不可展开（不可解释）部分的比例系统性提高却不降低被追责时的正确率与可校正性——则本条核心失效。反之，若「只让少数关键步显式化」（SLT / TaH）在人与模型两侧同时优于「全展开」与「全折叠」，则本条成立。
