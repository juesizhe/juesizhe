判准
判准不在同质度、团结度或规模，而在①**分**——差异的功能互补与分配（无「分」则只是叠加而非共同体）；②**交**——互补的回报是否**双向闭合**（单向即为寄生）；③**单向阀**——维持耦合的工程结构：价值可流入，而不可被权力 / 货币反向折算；④**不可让渡的余量**——各方保留可退出的余地，否则互补退化为吞并。**反直觉推论**：同质化满格（无摩擦的「我们」）不是共同体的极致，而是其消亡——当一切可共享，「我们」里就没有「我」，P9 的校正源随之归零。①**科学 2026**：Sacheli et al., *Sci Adv* 2026-04-17（人 fMRI + 猕猴颅内 LFP 跨物种）——人际协调既非被动节律同步（entrainment），也不依赖高阶「共享意图」，而是前运动皮层&#x7684;**「二元运动规划」（dyadic motor plan）：个体规划自身动作时前瞻性地把同伴应做的那一份纳入计算**——共同体的神经基底 = 把「他的份」纳入「我的计划」，是荀子之「分」在运动控制层的同构；Li、Shen 等（浙江大学），*Behav Sci* 2026;16(5):690——「we-mode」自发把**注意与记忆**组织在同伴目标周围（联合搜索中同伴目标项再认更优、注意增强，三天后保留并提升后续合作效率）；Kaandorp、Folke 等 25 位学者，*Cell Rep Sustain* 2026（10.1016/j.crsus.2026.100734）——人类嵌入生物圈的**三维度**：**构成性**（人体与肠道微生物共生、元素交织）、**关系性**（农耕 / 政策改土壤微生物再回作用于人体）、**演化性**（化学投入→微生物多样性降→作物营养降→长期影响健康与决策）：共同体无需奠基在「共享情感」上，**物质代谢的相互构成已是充分基底**；Vuong & Nguyen, *The Anthropocene Review* 2026-07——「**地球充足性**」（多物种共充足）与「**半导体原则**」（生态价值可流入经济，货币价值**不可**反向正当化不可逆生态损失）：**单向阀**是可操作化的共同体边界。②**儒**：《西铭》「民吾同胞，物吾与也」——伦理连带由血亲外推至万物；**《王制》「人何以能群？曰：分。分何以能行？曰：义」**——共同体成立于「分」（功能差异与定分）、维系于分配之「义」，**而非同质与共识**；《礼论》「养人之欲，给人之求」——礼即分配装置。③**佛**：僧伽「六和敬」——身和同住 / 口和无诤 / 意和同悦 / 见和同解 / 戒和同修 / **利和同均**：「和」不以抹平差异为条件，而以**同均**（分配）与**无诤**（口）为条件；华严「事事无碍」——相即相入而**各不失自位**：共生不必同质，恰是「不失自位」使互入成为可能。④**道**：《齐物论》「物固有所然，物固有所可」——差异各得其用；「物物而不物于物」——**不被所共生者吞没**；无为者不强设统一之同。⑤**墨 / 名**：墨「兼相爱，**交**相利」——「交」即**双向性**，普遍善意须由互利的可检验回路验证；名家名实——「共同体」一名兼三实：**认同共同体**（情感 / 我们感）、**规则共同体**（契约 / 制度）、**代谢共同体**（生态循环）；千古「德性 vs 契约 vs 生态」之争大半同名异实，唯一真矛盾是**互补与回报的结构性脱钩**。⑥**契约论（仅作抽象哲学资源取思辨，不涉任何政治立场）**：契约内核不是「同意」的文字，而是**双向可让渡、亦可撤回**——缔约者彼此不得单方面吞并对方，此即「不可让渡的余量」。⑦**地表伦理文献（真实可查）**：《地球宪章》（Earth Charter, 2000，**民间社会文件，非联合国通过**）「同一个人类大家庭与同一个地球共同体」；地球受托治理《海牙原则》——**人权植根于「生命共同体」的成员身份，自然与一切生命具内在价值**：三层共同体并列在其文本中确有其据；但草稿所称「2023 年联合国《地球共同体宪章》修订草案」经检索**无法证实**，依铁律不予引用。⑧**科幻 2026（极限反例）**：起点《共躯纪元》（2026-07）「意识共栖技术」把 2–9 人意识纳入同一躯体、共享寿命与资源，表面救世、实为把 94.9% 的人变成蜂巢公寓里的「共栖者」：**物质层共生满格 + 分配层寄生 = 共同体的赝品**；《蜂巢之梦》（2026-07）共享梦境中语言不再成隔阂、创新指数级涌现——无摩擦的「同」确能产出奇迹，问题在于**产出归谁、退出通道何在**。**关系**：与 P0 一致（共同体是**关系属性**而非成员的共同属性）；与 **P9 分工**——P9 判「偏私是否可被新证据修正」（**时间维**），P11 判「互补是否被双向回报与可退出边界约束」（**结构维**）；与 **P9（含已并入之 P10）互补**——个体侧需「非我之校正」，共同体则须**保留不可共享的余量**以维持校正源，无摩擦的「我们」消灭的正是「我」；与 **P7 同法异域**（皆以耦合度取代「量」为判准），对象不同——P7 论个体内「成本—回报」回路，P11 论主体间「互补—回报」回路。可证伪：若在高度同质、无退出通道的系统（强制共栖 / 蜂巢式融合）中，成员的能动感、创造力与系统长期存续**不降反升**；或若互补双向闭合的系统反比寄生系统**更早崩溃**，则核心失效。
